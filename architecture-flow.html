How it was built — agent workflow

🔍 Explore agents map code → 🧭 Plan agent designs approach → 🔨 Implement targeted edits → ✅ Verify agents (selftest.py offline checks + verify_ui.py headless Playwright render checks).

Risk score (risk.py)

score = min(100, base[CVSS×3.5 ≤35] + KEV[+28] + ransomware[+13] + network[+7] + exposure[≤10] + EPSS[×15]) → CRITICAL ≥75 · HIGH ≥50 · MEDIUM ≥30 · LOW <30

Data refreshes every 4 hours (or serves a bundled snapshot on serverless); feeds degrade gracefully; chart libraries are vendored locally.
